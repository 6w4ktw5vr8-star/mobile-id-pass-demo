# mobile-id-pass-demo

한국 모바일 신분증 PASS 앱 데모 프로토타입 (iOS)

## 개요
이 저장소는 "PASS 앱의 첫 화면" 느낌을 살린 SwiftUI 기반 데모입니다. 실제 PASS 앱과 동일하게 복제하기보다는, 비슷한 UI와 흐름을 재현한 프로토타입 형태로 구성했습니다.

## 포함 내용
- 검은 배경 기반 iPhone 스타일 UI
- 상단 상태바
- 큰 PASS 타이포그래피
- 상품권 카드형 배너
- 하단 앱 트레이와 탭 바
- SwiftUI 컴포넌트 구성

## 실행 방법
1. Xcode를 엽니다.
2. 새 SwiftUI App 프로젝트를 생성합니다.
3. 생성된 `ContentView.swift`와 `MobileIDPassDemoApp.swift` 내용을 프로젝트에 붙여넣습니다.
4. 에뮬레이터에서 실행합니다.

## 주요 파일
- `MobileIDPassDemoApp.swift`
- `ContentView.swift`

## 참고
이 데모는 실제 신분증 서비스/브랜드를 그대로 복제하는 용도가 아니라, "모바일 신분증/할인권 UI 데모"를 빠르게 구현하기 위한 시안입니다.
